## Funcionalidades

- 🧾 Carta completa con modificadores y cremas por producto
- 💳 Cobro en efectivo, tarjeta y pago mixto con cálculo de cambio
- 🖨️ Impresión de ticket (impresora térmica 72mm)
- 🔐 Login securizado con hash SHA-256
- 💵 Apertura de caja obligatoria al inicio del turno
- 📦 Control de stock en tiempo real
- ⚠️ Gestión de alérgenos (14 alérgenos EU)
- 🏷️ Descuentos comerciales configurables
- ⏸️ Pedidos aparcados y en curso
- 📊 Cierre de caja con cuadre de efectivo
- 💾 Exportación CSV y backup JSON
- ⭐ Temporadas (Premium sep–nov)
- 🎁 Tracker de regalos Horcus

## Stack

HTML + CSS + JS vanilla · localStorage · SHA-256 via SubtleCrypto · sin servidor · sin dependencias
